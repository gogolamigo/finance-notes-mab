這個網站把基礎金融觀念整理成清楚、可以持續增加的學習筆記。每篇從生活問題切入，再說明直覺、公式與假設，搭配自編例子、常見誤解和一題自我檢核。

製作：林泓基

專案特色

  • 所有文章共用同一套結構與版面。
  • 首頁支援關鍵字搜尋與分類篩選。
  • 概念清單下方以獨立提示呈現持續整理的方向，文章篇數只計算已完成的內容。
  • 每篇有四選一自我檢核，提交後提供逐選項解析。
  • 貨幣時間價值附有單筆複利試算，可觀察本金、年利率與時間的關係。
  • 使用原生 HTML、CSS、JavaScript；瀏覽網站不需要 API、登入或外部套件。
  • 所有案例都是教學假設，來源連結說明觀念依據。

內容與規則如何對應

AGENTS.md 說明專案目的、檔案位置、文章資料格式、視覺風格、公式規則、互動行為與新增內容的檢查方式。文章資料集中於 content.js，網站會依資料產生卡片、分類、篇數、文章與前後篇導覽。

因此，新增同類型文章時，只要完整加入一筆符合格式的內容，就能沿用現有版面與自我檢核，不需要重做整個網站。

檔案結構

檔案用途

瀏覽與開發

根目錄的 index.html 可以直接開啟，也可以由靜態網站服務提供。GitHub Pages 使用主分支根目錄即可發布。文章透過網址片段切換，因此不需要伺服器路由設定。

開發檢查使用 Node.js 18 以上版本，不需安裝套件。修改 Markdown 後，先執行 node scripts/documents.mjs 同步閱讀頁，再執行 node tests/check.mjs 與 node scripts/build.mjs。建置會確認閱讀頁與 Markdown 一致，再把網站需要的檔案複製到 dist/，根目錄仍保留完整原始碼。

首頁的專案規則與專案介紹連結會開啟排版後的閱讀頁，也能從閱讀頁下載對應的 Markdown 原始檔。公開網站及文件只保留作者姓名；課程交件所需的完整身分資料另填於 NTU COOL，不放入公開專案。

來源與 AI 協作

概念依據以 OpenStax 與 SEC Investor.gov 等一級來源為主，連結列在各篇底部。正文與例子以自己的方式整理，數值另行驗算。AI 協助內容整理、程式撰寫與檢查，專案規則用來保持各篇說明及介面的一致性。

延伸紀錄

初版包含貨幣時間價值、風險與報酬、債券價格與市場利率。延伸時，AI 依照同一份 AGENTS.md 新增第四篇「分散投資」，只在 content.js 增加一筆完整資料，沒有修改版面模板、互動程式或原有三篇內容。

實際檢查中，首頁自動更新為四篇，「風險與配置」分類能找到兩篇，也能搜尋到新文章。新文章的表格、自我檢核與前後篇導覽均正常呈現；53 組資料、語法與計算檢查通過。這次延伸顯示，明確的資料格式、內容規則與檢查流程，可以讓新增內容沿用同一套網站結構。
