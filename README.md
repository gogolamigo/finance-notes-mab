# 金融概念小教室

金融概念小教室是一個以台灣繁體中文撰寫的金融入門網站。我想把課堂上常見的觀念整理成可以慢慢閱讀的短篇筆記，先說清楚直覺，再介紹公式、條件與自編例子，最後用一題四選一檢查理解。

## 網站內容

- **貨幣時間價值**：單筆複利、現值與終值，附本金、利率、年數試算。
- **風險與報酬**：用簡單的機率情境理解期望報酬，認識平均值與實際結果的差別。
- **債券價格與市場利率**：理解固定票息與市場要求報酬率，以及債券價格的反向關係。
- **分散投資**：了解資產配置如何影響組合報酬，以及分散效果的限制。

網站提供文章分類、關鍵字搜尋、逐篇導覽、四選一練習、參考來源及適合窄螢幕閱讀的版面。案例均為自編教學假設，不構成投資建議。

## 專案規則

`AGENTS.md` 是這個專案的規則文件，包含網站目的、技術與檔案位置、視覺與閱讀架構、文章資料欄位、計算假設、互動方式、新增內容流程及驗收標準。新增文章時，先閱讀規則，再修改 `content.js` 內的資料，不需要為每篇複製新的 HTML、CSS 或互動程式。

## 本機閱讀與測試

需要 Node.js 18 以上。網站只使用 HTML、CSS 與原生 JavaScript，**訪客不需要安裝 Node.js**，也不需要登入或申請 API 金鑰。

1. 於專案根目錄執行 `node tests/check.mjs`。
2. 執行 `node scripts/build.mjs` 產生 `dist/` 與文件閱讀頁。
3. 在專案根目錄啟動靜態伺服器，例如 `python -m http.server 8000`，然後瀏覽 `http://localhost:8000/`。

`dist/` 中的檔案也可直接部署到靜態網站服務。GitHub Pages 可以使用預設分支的根目錄；本專案保留相對資源路徑，適用於儲存庫子路徑。

## 如何讓 AI 繼續新增內容

我先完成貨幣時間價值、風險與報酬、債券價格與市場利率三篇筆記，再依同一份 `AGENTS.md` 所定的資料格式與顯示方式，加入第四篇「分散投資」。文章會自動出現在相同的卡片清單、分類與前後篇導覽中，也沿用公式、例子、常見誤解、四選一及來源的結構。這證明規則的用途不只是讓 AI 完成一次性的網頁，而是協助後續內容使用一致的規格。

後續如果要新增其他金融概念，我會先確認資料與例子，再依規則加入一筆文章、執行測試並在瀏覽器檢查功能；不需要重新設計整個網站。
